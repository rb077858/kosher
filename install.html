התקנה כאפליקציה

הדרך המהירה: 5 דקות, בלי מחשב ובלי לאפס את הטלפון.

  1. מורידים את הקובץ

    בטלפון, נכנסים לאתר הזה ולוחצים הורדת APK, או סורקים את הברקוד שבעמוד הבית.

  2. מאשרים התקנה ממקור לא ידוע

    כשפותחים את הקובץ, אנדרואיד מבקש הרשאה לדפדפן להתקין אפליקציות. לוחצים הגדרות ← מסמנים אישור ממקור זה ← חוזרים אחורה.

    אם מופיעה אזהרה של Play Protect: פרטים נוספים ← להתקין בכל זאת.

  3. פותחים וסורקים את ברקוד מוסד הלימודים

    לוחצים "סריקת ברקוד מוסד" וסורקים את הברקוד שמנהל מוסד הלימודים מציג בפורטל, בלשונית "רישום מכשיר". מקלידים את שם התלמיד והכיתה.

  4. מאשרים הרשאות

    האפליקציה מובילה אתכם לכל הרשאה בנפרד:

    • נגישות: מזהה איזו אפליקציה נפתחה וחוסם אותה.
    • מנהל מכשיר: מונע הסרה פשוטה של המסנן.
    • גישה לנתוני שימוש: לזמני מסך.
    • VPN: לסינון אתרים. התעבורה לא עוברת דרכנו, רק שאילתות DNS לשרת הסינון.

  5. זהו

    המסנן פעיל. שינוי הגדרות דורש מעכשיו קוד מנהל.
