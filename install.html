התקנה כאפליקציה

הדרך המהירה: 5 דקות, בלי מחשב ובלי לאפס את הטלפון.

  1. מורידים את הקובץ

    בטלפון, נכנסים לאתר הזה ולוחצים הורדת APK, או סורקים את הברקוד שבעמוד הבית.

  2. מאשרים התקנה ממקור לא ידוע

    כשפותחים את הקובץ, אנדרואיד מבקש הרשאה לדפדפן להתקין אפליקציות. לוחצים הגדרות ← מסמנים אישור ממקור זה ← חוזרים אחורה.

    אם מופיעה אזהרה של Play Protect: פרטים נוספים ← להתקין בכל זאת.

  3. פותחים וסורקים את ברקוד המוסד

    לוחצים "סריקת ברקוד מוסד" וסורקים את הברקוד שמנהל המוסד מציג בפורטל, בלשונית "רישום מכשיר". מקלידים את שם התלמיד והכיתה.

  4. מאשרים הרשאות

    האפליקציה מובילה אתכם לכל הרשאה בנפרד:

    • נגישות: מזהה איזו אפליקציה נפתחה וחוסם אותה.
    • מנהל מכשיר: מונע הסרה פשוטה של המסנן.
    • גישה לנתוני שימוש: לזמני מסך.
    • VPN: לסינון אתרים. התעבורה לא עוברת דרכנו, רק שאילתות DNS לשרת הסינון.

  5. זהו

    המסנן פעיל. שינוי הגדרות דורש מעכשיו קוד מנהל.

התקנה כמנהל מכשיר (Device Owner)

המסנן מקבל שליטה ברמת המערכת. אפליקציות חסומות פשוט נעלמות, ואי אפשר להסיר את המסנן או לאפס את הטלפון בלי קוד מנהל.

שיטת ההתקנה הזו עדיין בפיתוח. אפשר להשתמש במדריך, אבל היכולות של מצב "מנהל מכשיר" (הסתרה מלאה, חסימת איפוס) יופעלו בגרסת האפליקציה הבאה.
התהליך מתחיל באיפוס הטלפון להגדרות יצרן, שמוחק את כל המידע. גבו תמונות, אנשי קשר וצ'אטים לפני שמתחילים.

חלק א׳ · הכנת הטלפון

  1. איפוס להגדרות יצרן

    הגדרות ← מערכת ← אפשרויות איפוס ← מחיקת כל הנתונים.

  2. אשף ההגדרה: בלי חשבון Google

    מתחברים ל-Wi-Fi, ובמסך חשבון Google לוחצים דילוג. את החשבון מוסיפים בסוף. אנדרואיד לא מאפשר להגדיר מנהל מכשיר כשיש חשבון בטלפון.

    • ב-Samsung: לא ליצור "תיקייה מאובטחת". ב-Xiaomi: לא להפעיל "מרחב שני".

  3. הפעלת אפשרויות מפתחים

    הגדרות ← אודות הטלפון ← לוחצים 7 פעמים על מספר Build. אחר כך: הגדרות ← מערכת ← אפשרויות מפתחים ← ניפוי באגים ב-USB.

חלק ב׳ · מהמחשב

  1. מתקינים את כלי ADB

    מורידים את SDK Platform-Tools מגוגל ומחלצים לתיקייה. פותחים חלון פקודות בתוך התיקייה.

  2. מחברים את הטלפון בכבל

    בטלפון מאשרים "לאפשר ניפוי באגים". בודקים שהמחשב מזהה אותו:

    adb devices

  3. מתקינים את האפליקציה

    מורידים את KosherGuard.apk לאותה תיקייה ומריצים:

    adb install KosherGuard.apk

  4. הופכים אותה למנהלת המכשיר

    adb shell dpm set-device-owner com.kosherguard.filter/.admin.AdminReceiver

    אמורה להופיע ההודעה Success: Device owner set.

חלק ג׳ · בטלפון

  1. פותחים את מסנן כשר וסורקים את ברקוד המוסד

    מכאן האפליקציה מגדירה הכל לבד: מכבה את ניפוי הבאגים, חוסמת איפוס ומצב בטוח, ומפעילה את הסינון.

  2. מוסיפים חשבון Google (אם רוצים)

    הגדרות ← חשבונות ← הוספת חשבון. Google Play יהיה זמין או חסום לפי המדיניות של המוסד.

התקנת מערכת ההפעלה הכשרה

גרסת אנדרואיד (GSI) שהמסנן והחנות הכשרה בנויים בתוכה. מתאימה לרוב הטלפונים מ-2019 ואילך שתומכים ב-Project Treble.

מערכת ההפעלה עדיין בבנייה ובבדיקות באמולטור. קובץ ההתקנה יפורסם כאן כשיהיה מוכן. המדריך מתאר את התהליך המלא.
התקנת מערכת הפעלה מוחקת את כל המידע ודורשת פתיחת bootloader. אחרי ההתקנה חלק מאפליקציות הבנקים ו-Google Wallet עלולות לא לעבוד. בצעו רק אם אתם מבינים את הסיכון.

חלק א׳ · בדיקת התאמה

  1. בודקים תמיכה ב-Treble

    מתקינים מ-Google Play את האפליקציה Treble Info. צריך לראות: Project Treble: supported, ארכיטקטורה arm64, ו-Seamless system updates (A/B או A-only).

  2. בודקים שאפשר לפתוח bootloader

    • Pixel, Motorola, Nothing, Sony: פתיחה פשוטה דרך fastboot.
    • Xiaomi: דרך Mi Unlock, עם המתנה של כמה ימים.
    • OnePlus: פתיחה פשוטה. בדגמים חדשים צריך לבקש קוד מהיצרן.
    • Samsung: לא מומלץ. רוב הדגמים בארץ נעולים לחלוטין.

חלק ב׳ · פתיחת bootloader

  1. מפעילים OEM Unlocking

    אפשרויות מפתחים ← ביטול נעילת OEM מופעל, וניפוי באגים ב-USB מופעל.

  2. נכנסים ל-bootloader ופותחים

    adb reboot bootloader
    fastboot flashing unlock

    בטלפון בוחרים בכפתורי עוצמת השמע Unlock ומאשרים בכפתור ההפעלה. הטלפון יימחק.

חלק ג׳ · צריבת המערכת

  1. מורידים את הקבצים

    kosheros-arm64.img ו-vbmeta.img בקרוב, לתיקיית platform-tools.

  2. עוברים ל-fastbootd

    fastboot reboot fastboot

  3. מבטלים אימות ומוחקים את המערכת הישנה

    fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img
    fastboot erase system

  4. צורבים ומאפסים נתונים

    fastboot flash system kosheros-arm64.img
    fastboot -w
    fastboot reboot

    ההפעלה הראשונה יכולה לקחת עד 5 דקות.

  5. הגדרה ראשונה

    מסנן כשר כבר מותקן כחלק מהמערכת. במסך הפתיחה סורקים את ברקוד המוסד, וזהו.

רוצים לנסות בלי טלפון?

אפשר להריץ את מערכת ההפעלה באמולטור של Android Studio במחשב. קובץ תמונה לאמולטור (x86_64) יפורסם יחד עם הגרסה לטלפונים.
